# 使用说明

## 新建下载

在任务列表点击「新建下载」，或按 `Ctrl+V` 粘贴影石 3D 时光舱公开分享链接。程序解析后列出当前可获取的原文件；不需要影石账号登录。

通过「浏览」选择基础文件夹，每条任务会在其下创建独立子文件夹。展开「下载内容」可选择资源，至少选中一个文件才能开始。实际文件类型以来源返回的清单为准：

| 资源 | 原格式 |
|---|---|
| 主模型 | SOG |
| 相机数据 | `cameras.json` |
| 体素归档 | ZIP |
| 效果视频 | MP4 |

首次默认选择主模型和相机数据。确认创建任务后，程序记住本次基础文件夹和资源类别的勾选/取消勾选，下次新建继续使用。取消弹层不会改变确认偏好；某类别在当前分享中缺失时，也不会抹掉原有偏好。修改或补下载旧任务不改变新建默认值。

## 管理任务

- 任务列表区分进行中、已完成和未完成任务；双击任务或使用展开操作可查看文件。
- 多条任务依次执行。传输结束后还会校验和发布文件，不能把字节进度达到 100% 当作完成。
- 有可用下载文件的任务，在悬停、选中或键盘聚焦时显示文件夹按钮。按钮打开对应任务的目录。
- 取消只请求停止当前执行，等待实际取消结果；已完成文件保留。重试时核对已有结果，未完成文件从头下载。
- 若输出位置存在无关或被修改的同名文件，程序报冲突并保留原文件；可移走或重命名冲突文件后重试，或取消该资源的勾选。
- 移除任务记录不等于删除已下载文件。

程序自动保存任务列表和偏好。重启后检查本地结果，不自动开始网络下载；再次下载时重新解析分享链接获取当前资源地址。程序不会把临时签名下载地址保存到计划中。

## 计划与编辑

下载计划 `.3dgsdl.json` 保存分享链接、资源选择和输出配置，不包含下载原文件或撤销历史。日常下载不需要先手动保存计划；计划导入/导出适合复用配置或配合 CLI。

| 快捷键 | 操作 |
|---|---|
| `Ctrl+N` | 新建下载 |
| 工作区 `Ctrl+V` | 粘贴链接新建；文本框中仍是粘贴文字 |
| `Ctrl+O` | 导入计划 |
| `Ctrl+S` / `Ctrl+Shift+S` | 保存计划 / 另存计划 |
| `Tab` / `Shift+Tab` | 移动键盘焦点 |
| 文本框 `Enter` / `Escape` | 提交有效编辑 / 放弃草稿；IME 组合输入优先 |
| `Ctrl+Z` / `Ctrl+Y` | 文本编辑时撤销/重做草稿，离开编辑态后撤销/重做计划编辑 |

撤销资源选择或文件名只影响计划，不删除原文件、不回退下载进度，也不会自动重新下载。

## 命令行

构建产物中的 `3DGSDownloaderCli.exe` 与桌面程序共用应用服务。下面的分享链接由用户输入，输出目录使用当前目录下的独立文件夹：

```powershell
$ShareLink = Read-Host '请输入影石 3D 时光舱公开分享链接'
$OutputDirectory = Join-Path (Get-Location) 'downloads'
$Cli = '.\build\windows-release\bin\3DGSDownloaderCli.exe'
& $Cli resolve $ShareLink --out '.\plan.3dgsdl.json' --output-dir $OutputDirectory
& $Cli inspect '.\plan.3dgsdl.json'
& $Cli download '.\plan.3dgsdl.json'
```

`resolve` 保存解析后的计划，`inspect` 查看配置，`download` 按计划下载。CLI 不读取桌面的资源选择偏好，下载前应检查计划的勾选项；完整计划编辑语法见 `3DGSDownloaderCli.exe --help`。下载时 `Ctrl+C` 请求取消。

## 已知限制

当前不支持需要登录的分享、格式转换、3D 预览、视频视角调整或跨进程断点续传。效果视频按来源原文件保存，画面视角不保证与交互式时光舱的当前视角一致。公开页面结构或分享权限变化可能导致解析失败，此时应先确认链接仍可公开访问。
