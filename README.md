# 3DGSDownloader

Windows x64 原生桌面工具，用于下载影石 3D 时光舱公开分享链接中的原文件，无需登录。

*made with love by Haodawei.*

## 下载

在 [GitHub Releases](https://github.com/davidhao2046/3DGSDownloader/releases) 下载 Windows x64 预览版 ZIP，完整解压后运行 `3DGSDownloader.exe`。包内包含 Skia 依赖和许可证；系统需安装最新版 [Microsoft Visual C++ v14 x64 运行库](https://aka.ms/vc14/vc_redist.x64.exe)及支持所需 Vulkan 扩展的显卡驱动。发布页提供 SHA-256 校验值和本版验证范围。

## 功能

- 一个分享链接对应一条任务，在列表中查看进度、展开资源和打开下载文件夹。
- 支持来源提供的 SOG 模型、`cameras.json`、体素 ZIP 和效果视频 MP4，保持原格式。
- 首次默认下载模型和相机数据；以后记住上次确认下载的文件夹和资源类别选择。
- 每条任务使用独立子文件夹，下载校验后发布，不覆盖已有文件。
- 自动保存任务列表和偏好，支持取消、重试以及补下载缺失文件。
- 提供命令行入口，便于解析链接、检查计划和下载文件。

## 使用

1. 点击「新建下载」，或在任务列表按 `Ctrl+V` 粘贴公开分享链接。
2. 通过「浏览」选择保存位置，按需展开「下载内容」调整文件选择。
3. 点击「开始下载」。完成后，将鼠标移到任务行，点击文件夹按钮查看结果。

重启会恢复任务记录并检查已有文件，不会自动开始网络下载。更多操作见 [使用说明](docs/usage.md)。

## 运行与构建

目前支持 Windows x64。桌面界面需要支持 Vulkan 1.1 及相关扩展的显卡驱动，使用系统字体显示中文。

源码使用 C++20、Win32、自有控件、Skia 栅格绘制和 Vulkan 呈现，构建采用 CMake/Ninja/MSVC。仓库不包含可执行文件、下载资源或本机运行数据。

构建脚本从官方 NuGet 获取锁定版本的原生 Skia DLL，并校验包、DLL 和许可文件。依赖要求、构建命令和测试方式见 [构建说明](docs/building.md)；发布流程见 [发布说明](docs/releasing.md)。

## 当前范围

- 仅支持影石 3D 时光舱公开分享链接，不处理需要登录或已失效的内容。来源页面变化可能影响解析。
- 下载原文件，不提供格式转换、3D 预览或视频视角调整。
- 多任务串行下载；未完成文件重试时从头开始，暂不支持跨进程断点续传。
- 支持中文输入与键盘操作；完整无障碍支持和跨设备显示兼容性仍需完善。
